# 銀行の顧客ターゲティング（SIGNATE 練習問題）

## 概要
銀行のキャンペーン電話において、顧客が定期預金を申し込むかどうかを予測する課題です。

- **コンペURL**: [SIGNATE - 銀行の顧客ターゲティング](https://signate.jp/competitions/1)
- **学習内容**: 二値分類（Binary Classification）

## 使用したモデルと結果
1. **ロジスティック回帰**: 
   - 精度（AUC）: 0.8989314635698766
   - 特徴: 線形な関係性を把握するためにベースラインとして作成。
2. **ランダムフォレスト**: 
   - 精度（AUC）: 0.9014560785181225
   - 特徴: 特徴量の重要度を確認し、非線形な関係を捉えることで精度が向上。

## 工夫した点
- 欠損値の処理や、カテゴリ変数のダミー変数化（One-Hot Encoding）。
- ランダムフォレストによる特徴量の重要度分析。
